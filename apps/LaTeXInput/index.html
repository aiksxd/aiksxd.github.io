使用说明

  • 在输入区域使用Markdown语法输入内容（支持LaTeX公式）
  • 按下Ctrl + L切换到LaTeX模式（再次按下可退出）
  • 在LaTeX模式下，输入关键词会自动显示匹配的LaTeX符号
  • 使用↑ ↓键选择建议，Tab键补全
  • 按下Ctrl + Enter提交内容到显示区域
  • 以下是一些可用关键词示例：

希腊字母

alpha → α

beta → β

gamma → γ

运算符

times → ×

div → ÷

pm → ±

分数/积分

frac{a}{b} → 分数

int → ∫

sum → ∑

其他符号

infty → ∞

sqrt → √

neq → ≠

## 首页首屏加载优化 + 文章深链

- 根因：`index.html` 的 `data-intro=1` 把云/日月/头像按在隐藏态，但开场推进器写在 `js/blog.js`（defer 且排在 6 个脚本最后）。首访必须等 `posts.data.js`(112KB) + `highlight.min.js`(125KB) + `reader.js` + `blog.js` 全部下载执行完才开始计时，表现为「先黑一阵再一起出现」。
- 改动：
  1. 开场三级推进（140/1140/1560ms）前移到 `<head>` 内联脚本，CSS 就绪即起步；`blog.js` 的 `initHeroIntro` 降级为兜底（靠 `window.__cbHero.inline` 区分），`initAxWriting` 用 `axDone` 旗标补接可能错过的事件；新增 `hero-intro-final` 事件。
  2. `posts.data.js` / `highlight.min.js` 移出 defer 链，URL 记在 `window.CB_ASSETS`，`reader.js` 的 `loadReaderAssets()` 首次开文时按需插入并缓存 Promise；`openFullscreen` 起手预取，落位时等资源就绪再揭开正文，避免空正文跳字。
  3. `index.html` 加 7 个 `preload as=style`（与 `@import` 同 URL 同哈希）消除 CSS 瀑布流；头像加 `preload as=image` + `fetchpriority=high`。`tools/build.mjs` 补上漏掉的 `mobile-lite.css` 层，并在 HTML preload 上同步打戳。
  4. 深链：`?post=post-N`（别名 `article` / `p`，纯数字自动补 `post-`）。`initSplit` 注入 `revealPost` 把目标卡挪进当前页并锁定；`runPostDeeplink` 等开场结束后两段滚动（先 `#posts` 再 `.split+80`）播视差与流星线，1900ms 时全屏打开。
- 验证：`node --check` 通过；`node tools/build.mjs` 刷新戳后 `--check` 通过（顺带修掉 split.css / mobile-lite.css 的陈旧戳）；用 Node vm + 假定时器对内联开场脚本和深链编排各做一轮断言烟测，全绿。环境无 Playwright/Puppeteer，未做真实浏览器截图。

## HTML 参与构建的收益量化 + 手机目录抽屉化（同日续）

- 量化 `index.html` 参与构建的收益：原始 46926B / gzip 16076；去注释 37826 / 11243（-30.1%）；去缩进 33133 / 10893（-32.2%）；极限紧凑 32635 / 10808（-32.8%）。结论：只去掉 HTML 注释就能省约 4.8KB gzip（首屏总量 54KB 的 9%），但 index.html 是唯一手写源（开场内联脚本、语言协商、卡片 DOM 全在里面），把它变成"产物"会增加构建链路与排障成本，边际收益低。当前压缩重点应放在正文图片（已做）而非 HTML；结论为不建议。
- 手机目录抽屉化：原 `mobile-lite.css` 里是"几乎全宽的圆角浮层"（calc(100vw - 20px)），渲染观感差。改为左侧滑入抽屉：`width: min(82vw, 340px)`、fixed、贴左、`border-radius: 0 14px 14px 0`，DOM 与样式完全复用桌面 `.reader__toc`（标题/编号/层级/高亮同源），只在定位上分档。
- 新建 `.toc__scrim` 遮罩（reader.css 默认 display:none，mobile-lite 媒体查询内 display:block）：层级 正文 auto < 遮罩 1 < 标题栏 2 < 抽屉 3 —— 关键点是标题栏那颗开关按钮要露在抽屉之上，展开后同一颗按钮仍能收起（与桌面端操作逻辑一致）。遮罩点击也收起。
- JS（reader.js）：`LITE` 常量改为 `isLite()` 函数，跨断点 resize 时按当前档位 toggle `is-toc-folded`（手机收起/桌面展开）；手机点目录条目后自动收起抽屉（不收起则盖住刚跳到的正文，桌面并列不收）；切语言重建时一并清掉 `.toc__scrim`，避免留旧遮罩或叠加。
- 修掉一个真 bug：reader.css 里 `is-head-collapsed .toc__scrim` 原写 `top: 8px`（旧浮层残留），抽屉起点已改成 44px，标题栏折走后应贴到 0，已统一为 0。
- 验证：build/minify/md2html 三套 check 全过；12 项 CSS 规则 + JS 接线断言全绿（分 reader.css 独立直引与 site.css 合并产物两处查）。本地服务器 `python -m http.server 8765` 仍开着，深链 `?post=这个博客的骨架` 已刷新预览。
